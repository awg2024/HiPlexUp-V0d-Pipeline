### V0d Histological Analysis Workflow 

The aim of this repository is to identify and quantify V0d interneurons from multiplex histological images

1. Python conversion from czi into a via read_czi.py into a 16-bit multichannel TIFF for analysis and an 8-bit composite preview image. 

2. Initial FIJI image quality control. Before segmentation or cell measurement, each converted image is checked for staining quality, tissue quality, anatomical orientation (what are the left/right hemicords? understanding what is dorsal/ventral). Labelling the samples as PASS, FLAG, EXCLUDE, would we exclude the entire sample? or individual hemicords? or individual tissue regions?  

3. Define tissue ROI for analysis. In this part of the workflow we will be analysing/counting the whole spinal cord section but the czi images do include the surrounding background so cropping them will help for classification, additionally the HiPlex R script expects cropped spinal sections for this. For this step this will take place in `tissue_roi.py` for the user to manually select the ROI spinal cord for each sample. This ROI step is essential for cellpose so it doesn't segment background artifacts (false positives). The output will just be a cropped .tiff file with the background being transparent which is acceptable for cellpose. 

4. Cell segmentation using CellPose. In this stage, we will utilise the pre-trained model offered by the Opensource software cellpose and run this for our samples identifying individual cellular objects. Discuss with supervisor what is the best channel for actually identifying cells (ideal if we have a clear nucleus stain; likely VGAT?). Analysis will be conducted in `run_cellpose.py` in this step. After the model has finished analysing a few samples we will be able to get a unique ID for each cell and also a mask for each sample. This can then visualised using original fluorescence sample image + cellpose segmentation mask/outlines (e.g. masks/Slide139_Scene1_mask.tif) and we can see what cells have been identified.

10. Cellpose segmentation quality check. Ok so utilising the visualisation of fluorescence image + cellpose produced from the `run_cellpose.py` script we will need go through each sample and check for missed cells (visible cell), merged cells (two neighbouring cells have been incorrectly interpreted as one cell), split cells (one biological cell has been incorrectly divided into as one cell), false positives (objects, background fluorescence, blood vessels etc.), poor cell boundaries, manual correction. So after analysing this it will most likely have several issues as this was a pretrained unspecialised ML model that was utilised, so in Fiji we can adjust / add masks to the .tiff file, then we can train the cellpose model again then re-analyse with more sample traces. However if its terrible predictions and completely off the mark for classifications we will just need to train a new cellpose model training with (10/20/70). This depends on how well V0ds are displayed in the RNAiscope? Or is it a better approach to apply select channels together to gather objects/cells in the staining then proper v0d/non-v0d analysis can happen later on. 

  
14. Once reliable masks do exist of V0d cells exist. You have four raw, unsegmented fluorescence images: VGAT, PAX2, EVX1, DBX1, all from the same physical tissue section, same pixel grid, perfectly aligned (since they're just different channels of one multiplex image, not different images). For cell_0001, you already know exactly which pixels belong to it (from the mask). So you just go to those same pixel coordinates in each of the four channel images and read off the fluorescence values there (vgat mean/sd, dbx1 mean/sd etc., xy coordinates). This step will utilise `measure_cells.py`. Here this script will then generate a complete cell-level dataset. Here in this step we will export a csv/xsls in which each row represents a segmented cell (including cell id, image id, animal id, vgat mean, vgat sd, vgat corrected, classifcation (EMPTY).

15. Identification of V0d cells. This is the step that requires the knowledge of what a V0d cell would look like in this staining. We have a large dataset of identified cells but which ones are actually V0d cells? Here the user will need have this knowledge of what staining is expected? VGAT, PAX2, EVX1, DBX1, morphology, anatomical location. So we will classification of each cell as V0D, NON-V0D, borderline cell. And critically why are we considering this a V0d cell? (fiji software used in this step). Useful helper script for this `prepare_labels.py` with the workflow of reviewing all VGAT, PAX2, EVX1, DBX1 cells and assigning biological identity, this script will reduce the overhead for the marker. Blinding the counter to what SOD1/WT are to avoid any assumptions. 

16. Merge labels with measurments. `prepare_labels.py` combining the .csv all_cells and then the v0d label.csv. so we then ultimately have per-row dataset with each cell is a cell but we now have this classification along side it, so it's cell id, image id, vgat mean, sd etc.. and then also the classification we've given it.

17. Examine the quantitative characteristics of the v0d cells. Once cells have been classified biologically, examine whether V0d cells have measureable characteristics that distinguish them from non-V0d cells. This analysis should occur after the expert classification so we can assign thresholds grounded in truth. Then we can plot the distribution of VGAT, PAX2, EVX1, DBX1 intensity of V0d and non-V0d cells. The script for this workflow would be `analyse_labels.py`. Here in these distributions we are wanting to see a clear distinct profile of a V0d cell that doesnt match a non-V0d cell and then we can confidentely say given these thresholds of VGAT, PAX2 etc.. this is definitely a v0d cell since this doesn't overlap with the non-V0d cells.

18. An optional extensive if the distributions look insanely clear we could re-run the pipeline with only these thresholds and see if we can accurately classify the V0d cells without any manual marking using `validate_V0d_rules.py`, this is a cool extension that would provide researchers a cool model in the future for v0d classification.

19. HiPlexUP spatial and quantitative analysis. `Montañana-Rosell_et_al_2023__HiPlexUp.R` this script will be adapted with our new found thresholds to identify v0d cells, and then to count for WT, SOD1, but apart from that it will remain largely unchanged. This pipeline contains methods for assigning animal id, coordinate transform, spinal cord rotation, left/right hemicord normalisation, tissue size normalisation, cell-size filtering, marker-based population analysis, cell counting, spatial plotting. The existing HiPlexUP workflow therefore provides the downstream spatial analysis framework rather than having to recreate this analysis from scratch.

20. `publication_plotting.py` this will take in some neccessary csv and plot for the publication in a svg format for inkscape adjustment for the panel. We want to have WT/SOD1 V0D cell counts and intensity in the end result.
