### V0d Histological Analysis Workflow 

The aim of this repository is to identify and quantify V0d interneurons from multiplex histological images

1. Python conversion from czi into a via read_czi.py into a 16-bit multichannel TIFF for analysis and an 8-bit composite preview image. 

2. Initial FIJI image quality control. Before segmentation or cell measurement, each converted image is checked for staining quality, tissue quality, anatomical orientation (what are the left/right hemicords? understanding what is dorsal/ventral). Labelling the samples as PASS, FLAG, EXCLUDE.

3. Define tissue ROI for analysis. In this part ofthe workflow we will be analysing/counting the whole spinal cord section but the czi images do include the surrounding background so cropping them will help for classification, additionally the HiPlex R script expects the sections this. For this step this will take place in `tissue_roi.py` for the user to manually select the ROI spinal cord. This ROI step is essential for cellpose so it doesn't segment background artifacts (false positives). 

4. Cell segmentation using CellPose. In this stage, we will utilise the pre-trained model offered by the Opensource software cellpose and run this for our samples identifying individual cellular objects. Here, we do not expect the cellpose segmentation have the accuracy/knowledge to accurately classify V0d/Non-V0d cells we just want a classification of all cells. We will need to apply the correct segmentation channel as CellPose needs a consistent physical anchor to map cell boundaries. In this case we will use VGAT, a primary synaptic vesicle/transmitter-release marker but it will not stain the entire cell-body. Analysis will be conducted in `run_cellpose.py` in this step. After the model has finished analysing a few samples we will be able to get a unique ID for each cell and then these cells can be visualised as original fluorescence image + cellpose segmentation outlines (e.g. masks/Slide139_Scene1_mask.tif). 

5. Cellpose segmentation quality check. Ok so utilising the visualisation of fluorescence image + cellpose produced from the `run_cellpose.py` script we will need go through each sample and check for missed cells (visible cell), merged cells (two neighbouring cells have been incorrectly interpreted as one cell), split cells (one biological cell has been incorrectly divided into as one cell), false positives (objects, background fluorescence, blood vessels etc.), poor cell boundaries, manual correction. So after analysing this it will most likely have several issues as this was a pretrained unspecialised ML model that was utilised, so in Fiji we can adjust / add masks to the .tiff file. Just to reiterate this aim in this part of the workflow it is not to identify V0d cells it's to identify cells in the staining. (is this the path of least resistance?) 

6. Once reliable masks exist of cells exist, each cellpose object can be measured against the original 16-bit microscopy channels. this step will utilise `measure_cells.py`, (hm i dont understand this part? if each cell has a unique mask ID, exactly the cell boundaires can be applied to vgat, pax2, evx1, dbx1. this ensures that fluorscience measurements across channels correspond to the same physical cell, so we run cellpose individually on each channel? then compare to get a definite cell? for every cell measure we can get a identification of cell_id, image_id, animal_id, slide_id and scene_id, x,y coordination -- typically the centeroid of the cell mask, morphology flourscence intensity as well of each vgat, pax2, evx1. again this step is all just classifying every cell in the staining it's not to do with specficially selecting v0d cells.

7. Ok so after we have all these statistics for each cell we need to ensure the raw fluorescence intensity is influenced by background staining. So from each channel we can calculate the background staining intensity, empty area slide area around spinal cord this is calculated in `read_czi.py`. Then we will calculate the mean channel cell mean, so we calculate the corrected intensity. For example, VGAT_corrected = VGAT_cell_mean - VGAT_background. This calculations will be done in `measure_background.py`. This will serve as a step but this is more of helper function that gets called by `measure_cells.py`

8. Generate the complete cell-level dataset. Here in this step we will export a csv/xsls in which each row represents a segmented cell (including cell id, image id, animal id, vgat mean, vgat sd, vgat corrected, classifcation (EMPTY). this will actually be the final step of the processing for the `measure_cells.py`.

9. Identification of V0d cells. This is the step that requires the knowledge of what a V0d cell would look like in this staining. We have a large dataset of identified cells but which ones are actually V0d cells? Here the user will need have this knowledge of what staining is expected? VGAT, PAX2, EVX1, DBX1, morphology, anatomical location. So we will classification of each cell as V0D, NON-V0D, borderline cell. And critically why are we considering this a V0d cell? (fiji software used in this step). Useful helper script for this `prepare_labels.py` with the workflow of reviewing all VGAT, PAX2, EVX1, DBX1 cells and assigning biological identity, this script will reduce the overhead for the marker. 

10. Merge labels with measurments. `prepare_labels.py` combining the .csv all_cells and then the v0d label.csv. so we then ultimately have per-row dataset with each cell is a cell but we now have this classification along side it, so it's cell id, image id, vgat mean, sd etc.. and then also the classification we've given it.

11. Examine the quantitative characteristics of the v0d cells. Once cells have been classified biologically, examine whether V0d cells have measureable characteristics that distinguish them from non-V0d cells. This analysis should occur after the expert classification so we can assign thresholds grounded in truth. Then we can plot the distribution of VGAT, PAX2, EVX1, DBX1 intensity of V0d and non-V0d cells. The script for this workflow would be `analyse_labels.py`. Here in these distributions we are wanting to see a clear distinct profile of a V0d cell that doesnt match a non-V0d cell and then we can confidentely say given these thresholds of VGAT, PAX2 etc.. this is definitely a v0d cell since this doesn't overlap with the non-V0d cells.

12. An optional extensive if the distributions look insanely clear we could re-run the pipeline with only these thresholds and see if we can accurately classify the V0d cells without any manual marking using `validate_V0d_rules.py`, this is a cool extension that would provide researchers a cool model in the future for v0d classification.

13. HiPlexUP spatial and quantitative analysis. `Montañana-Rosell_et_al_2023__HiPlexUp.R` this script will be adapted with our new found thresholds to identify v0d cells, and then to count for WT, SOD1, but apart from that it will remain largely unchanged. This pipeline contains methods for assigning animal id, coordinate transform, spinal cord rotation, left/right hemicord normalisation, tissue size normalisation, cell-size filtering, marker-based population analysis, cell counting, spatial plotting. The existing HiPlexUP workflow therefore provides the downstream spatial analysis framework rather than having to recreate this analysis from scratch.

14. `publication_plotting.py` this will take in some neccessary csv and plot for the publication in a svg format for inkscape adjustment for the panel. We want to have WT/SOD1 V0D cell counts and intensity in the end result.
